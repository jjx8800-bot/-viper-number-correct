# البحث عن الرقم الصحيح — Viper

نسخة أولية مرتبطة بـ Brave Web Search API.

## التشغيل

1. ثبّت Node.js 18 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. ضع مفتاح Brave في `BRAVE_API_KEY` داخل `.env`.
4. شغّل:

```bash
npm install
npm start
```

5. افتح `http://localhost:3000`.

## ملاحظة مهمة

البرنامج يبحث في الويب العام ويستخرج أرقامًا مرشحة من نتائج البحث. لا يعتبر أي رقم رسميًا تلقائيًا؛ يجب فتح المصدر والتحقق منه. لا تضع مفتاح Brave داخل ملفات `public` أو داخل تطبيق العميل.
